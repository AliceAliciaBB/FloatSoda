# コントローラーの入力を受け取る

> このページは執筆前の骨組みです。設計シートとト書きだけを置き、本文はまだ書いていません(追跡: #219)。

  - 共通の性質と専門用語の扱い: CONTRIBUTING.md の「ドキュメントのトンマナ」の「読み手」

- 依頼の解釈: 画面上のボタンを押す操作(ポインタ)は、このページに含めない。「ボタンやトグルを組み立てる」で扱う
- テーマファイル: how-to
- Why(目的): ショートカットや掴む操作など、画面の外のコントローラー入力を使う物を作れるようにする
- What(目標・結果): トリガーを引くとコンソールに表示が出る。値は `Value` で毎フレーム読める
- How(手段): アクションを宣言する → `FloatSodaOptions` に登録する → イベントまたは `Value` で受け取る → SteamVR のバインディングを確かめる
- 要素:
  - アクションは `InputAction<T>` で宣言する。`T` は `bool`(ボタン)、`float`(トリガーの引き量)、`Vector2`(スティック)のいずれか(`src/FloatSoda.OVR/Input/InputAction.cs`)
  - 宣言に必要なのは `Name`。割り当ての提案は `SuggestedPath` か `DefaultBindings` で書く(`src/FloatSoda.OVR/Input/InputAction.cs`)
  - アクションは `InputActionMap` にまとめ、`FloatSodaOptions.InputActionMaps` に渡す(`src/FloatSoda.OVR/Input/InputActionMap.cs`、`src/FloatSoda/FloatSodaOptions.cs`)
  - 1つ以上登録すると、アクションマニフェストが自動生成されて SteamVR に登録される(`src/FloatSoda/FloatSodaOptions.cs`)
  - 受け取りは `OnPerformed`、`OnReleased`(`bool` のみ)、`Value` を使う(`src/FloatSoda.OVR/Input/InputAction.cs`)
  - 実際のバインディングを決めるのは SteamVR で、利用者が SteamVR のバインディング画面から変えられる(`samples/FloatSoda.Samples.OverlayApp/Program.cs` のコメント)
  - 入力の初期化に失敗してもオーバーレイの表示は続く。警告のログが出る(`src/FloatSoda/FloatSodaApp.cs`)
  - 実際のコード例は `samples/FloatSoda.Samples.OverlayApp/Program.cs` の `grab` にある
  - ゲーム本体(シーンアプリ)が同じ入力を使っているときの優先順位は SteamVR のアクションセットの優先度に従う。使われていない入力を提案すると衝突しにくい(前の docs の注意。※要確認)
