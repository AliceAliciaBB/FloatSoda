# 反応しないときに切り分ける

> このページは執筆前の骨組みです。設計シートとト書きだけを置き、本文はまだ書いていません(追跡: #219)。

## 設計シート

- 分類: 説明型(Diátaxis: how-to)
- 読み手: だれが / VRChatter、Booth クリエイター、uGUI を避けたいエンジニア。ボタンを押しても反応しない、数字が変わらない、文字が出ないなど、エラーが出ずに動かない / 何を知っている / エラーのログは出ていない。動かし方は知っている / 読んで何をしたい / 制約によるものか、自分の書き間違いかを切り分けて、直したい
  - 共通の性質と専門用語の扱い: CONTRIBUTING.md の「ドキュメントのトンマナ」の「読み手」
- 出力言語と文体の指定: 日本語。敬体。トンマナは CONTRIBUTING.md の「ドキュメントのトンマナ」に従う
- テーマ: エラーが出ないのに期待どおりに動かないとき、症状ごとに原因を切り分ける手順
- 依頼の解釈: 起動できない、例外が出るなどのエラーが出る場合は、このページに含めない(「エラーを読んで直す」へ送る)
- テーマファイル: how-to
- Why(目的): FloatSoda の制約を、自分の書き間違いと取り違えて時間を失わないようにする
- What(目標・結果): 症状から、制約か書き間違いかが分かり、直せる場合は直る
- How(手段): 症状ごとの節を並べる。各節は「症状、まず確かめること、制約の場合、書き間違いの場合」の形で揃える。チュートリアルの「できなかったら」から、症状ごとの節へ直接リンクする
- 要素:
  - ポインタ座標が届くのはダッシュボードのオーバーレイだけで、`WorldSpaceWindow` と `DeviceTrackedWindow` では `GestureDetector` のコールバックが呼ばれない(`README.md` の「開発ステータス」、追跡: #182)
  - デスクトップの窓で動いても、ダッシュボードで動く証明にならない(`CONTRIBUTING.md`、追跡: #182)
  - `GestureDetector` は、子のある範囲でだけ反応する。空白を含む領域で反応させるには `Behaviour = HitTestBehaviour.Opaque` を指定する(`samples/FloatSoda.Samples.GestureDetector/README.md`)
  - `OnTap` は押して離した時点で成立する(`samples/FloatSoda.Samples.GestureDetector/README.md`)
  - `AbsorbPointer` と `IgnorePointer` は、ヒットテストを止める、または素通りさせる(`README.md` の「入力系」)。重ねたウィジェットの上側が押せなくしている場合がある
  - `SetState()` を使わずに値を書き換えると、画面が変わらない(`samples/FloatSoda.Samples.OverlayApp/CounterWidget.cs` の `SetState(...)` と対比)
  - `Size` を指定していないウィンドウは、起動後に中身の大きさが変わっても、SteamVR 上の表示が最初の大きさのままになる(`CHANGELOG.md`、追跡: #285)
  - スクロール系のウィジェット(`ListView`、`GridView`、`SingleChildScrollView`)は内部のスタブで、使えない(`README.md` の「まだ使えないもの」、追跡: #219)
  - `Button` などの UI コンポーネントは未提供で、押下も未反応(`README.md` の「まだ使えないもの」、追跡: #219)
  - 画像は `Paint.Image`、アイコンは `Paint.Icon` を使う(`README.md` の「まだ使えないもの」)
  - 文字が出ないときは、`Text` / `RichText` の色が背景と同じでないか、大きさが 0 でないかを確かめる(`src/FloatSoda/Widgets/Text.cs`。※要確認)
  - 直らないときの行き先は、ガイドの「5. 困ったとき」の入口ページの「どこでだれに聞くか」にある(docs 再編の決定、2026-10-16)
- 見出し:

  - ボタンを押しても反応しない
  - 数字や文字が変わらない
  - 文字や画像が出ない
  - 表示の大きさが更新されない
  - ほかの種類のオーバーレイで試した場合
  - それでも直らないとき
- ※要確認:
  - `GestureDetector` のボタンが、ダッシュボードのオーバーレイで実機で反応するか(HMD で確かめる)
  - 文字が出ない原因の網羅(フォント未解決、サイズ 0、色の一致など)。`samples/FloatSoda.Samples.Text` を読んで、実際に再現できるものだけを書く
  - 重ねたウィジェットが互いのヒットテストを塞ぐ場合の見分け方(`Stack` の上下で再現して確かめる)
  - 同じ `Title` で2つのウィンドウを作ったときに片方が出ない可能性(`src/FloatSoda/FloatSodaApp.cs` の `_bindings.TryAdd` を読んで確かめる)

## ト書き

### 最初に、症状を1つ選ぶ

- 読み手が持って来るもの: 動かないという現象
- このページが渡すもの: 症状ごとの節の一覧と、まず確かめる2点(どの種類のオーバーレイか、ログにエラーが出ていないか)。エラーが出ていれば「エラーを読んで直す」へ送る
- 読み手がすること: 症状を1つ選ぶ
- 次へ進む先: 選んだ症状の節

### ボタンを押しても反応しない

- 読み手が持って来るもの: 押しても何も起きないボタン。チュートリアルの段3の「押しても反応しない」からここへ来る
- このページが渡すもの: 切り分けの順番。(1) ダッシュボードのオーバーレイか、(2) 押せる範囲に子があるか(`Opaque` の指定)、(3) 上に重なって塞いでいるウィジェットがないか、(4) `OnTap` が押して離した時点で呼ばれること
- 読み手がすること: 順に確かめる
- できた?: ボタンを押すと反応する
- 止まる箇所: ダッシュボード以外で押したい場合。直せない制約であることを伝え(追跡: #182)、リファレンスの「できないこと・まだ使えないもの」へ送る
- 次へ進む先: 「それでも直らないとき」

### 数字や文字が変わらない

- 読み手が持って来るもの: 値は変わっているのに、画面が変わらない。チュートリアルの段2の「数字が変わらない」からここへ来る
- このページが渡すもの: `SetState()` を使っているか、`State` のフィールドを書き換えているかの確かめ方。「状態と作り直し」へのリンク
- 読み手がすること: 値を書き換える処理を `SetState()` の中に入れる
- できた?: 値が変わると画面が変わる
- 次へ進む先: 「それでも直らないとき」

### 文字や画像が出ない

- 読み手が持って来るもの: 文字や画像が出ない画面。チュートリアルの段2の「文字が出ない」からここへ来る
- このページが渡すもの: 確かめる順番(色が背景と同じでないか、大きさ、画像の読み込みが終わっているか)。画像は `Paint.Image`、アイコンは `Paint.Icon` を使うこと
- 読み手がすること: 順に確かめる
- できた?: 文字や画像が出る
- 次へ進む先: 「それでも直らないとき」
- 【未決】文字が出ない原因の節を、このページに置くか、「見た目を整える」の「うまくいかないとき」に置くか

### 表示の大きさが更新されない

- 読み手が持って来るもの: 中身が変わっても、SteamVR 上の窓の大きさが変わらない
- このページが渡すもの: `Size` を指定しないと、最初の大きさのままになる既知の問題(追跡: #285)と、中身の大きさが変わるウィンドウには `Size` を指定すること
- 読み手がすること: `Size` を指定する
- できた?: 表示の大きさが指定どおりになる
- 次へ進む先: 「それでも直らないとき」

### ほかの種類のオーバーレイで試した場合

- 読み手が持って来るもの: `WorldSpaceWindow` や `DeviceTrackedWindow` で押せない
- このページが渡すもの: 表示専用であること(追跡: #182)と、「オーバーレイの種類と選び方」へのリンク
- 読み手がすること: ダッシュボードに替えて試す
- 次へ進む先: 「それでも直らないとき」

### それでも直らないとき

- 読み手が持って来るもの: 直らない症状
- このページが渡すもの: ガイドの「5. 困ったとき」の入口ページの「どこでだれに聞くか」へのリンク。聞くときに添える情報(症状、窓の種類、再現するコード)
- 読み手がすること: 聞く
- 止まる箇所: なし。ここでページは終わる
