- 要素:
  - ポインタの座標が届くのはダッシュボードのオーバーレイだけである。`WorldSpaceWindow` と `DeviceTrackedWindow` に `GestureDetector` を置いても、コンパイルは通り例外も出ないが、コールバックは呼ばれない。回避は、操作が要る画面を `DashboardWindow` に置くこと。追跡: #182(AGENTS.md の「Widget/Element Tree」、`docs/` 旧版の GettingStarted の記述)
  - `Size` を省略したウィンドウは、起動後に中身の大きさが変わっても、SteamVR 上の表示が最初の大きさのまま更新されない。回避は、中身の大きさが変わるウィンドウに `Size` を指定すること。追跡: #285(CHANGELOG.md の「Known issues」)
  - `Size` を省略すると幅の上限が無いため、`Wrap` は折り返さずに横一列に並べる。回避は `Size` を指定すること(再編前の `docs/GettingStarted.md` の記述。`samples/FloatSoda.Samples.Wrap/README.md` で確かめる)
  - `ListView`、`GridView`、`SingleChildScrollView` は `internal` で、公開 API から使えない。回避は、`Stack` と `Positioned` などで自分で並べること。追跡: ※要確認(該当する未完了の Issue を特定できていない。`src/FloatSoda/Widgets/Layout/ListView.cs`)
  - `Button` などの UI コンポーネント(`FloatSoda.UI`、`FloatSoda.UI.Cream`、`FloatSoda.UI.FizzyPop`)は NuGet に出していない(`IsPackable=false`)。回避は、`GestureDetector` でボタンを組み立てること。追跡: #126(ロードマップ)、#102(`ButtonBase` の接続)、#78 と #100(`Button`)(AGENTS.md の「Project Structure」)
  - 文字入力(TextField)がない。追跡: #107
  - `Text` に折り返しと省略(`softWrap`、`overflow`、`maxLines`)の指定がない。追跡: ※要確認(Issue が見つからない。`samples/FloatSoda.Samples.Text/README.md`)
  - アニメーションは `AnimationController`、`Curves`、`FadeTransition` が使える。`Tween`、`CurvedAnimation`、暗黙的アニメーション(`AnimatedContainer` 系)、スプリングの物理シミュレーションは未実装である。追跡: #137、#163、#164
  - バックグラウンドスレッドから `SetState` を呼ぶと、UI の更新が失われる、またはクラッシュする。回避は、メインスレッドへ戻してから呼ぶこと。追跡: #150、#281
  - ウィンドウを閉じる API がない。追跡: #218
  - 実行中にオーバーレイの種類を切り替えられない。追跡: #90
  - SteamVR が起動していない状態でのアプリの起動、遅延接続、再接続は扱えない(`--desktop` でも OpenVR を初期化するため、SteamVR の起動は要る)。追跡: #140、#233(再編前の `docs/GettingStarted.md` の記述)
  - 通知として出して消す機能(トースト)がない。追跡: #123。※要確認(オーバーレイの表示と非表示を切り替える手段は `OVR` 層にあるが、ウィジェット層からの出し入れの手順を確かめていない)
  - ポインタ入力の不具合: `Transform` で拡大・回転した子の見た目の部分を押しても反応しない(追跡: #298)。クリップ系ウィジェットは、クリップの外を押しても子が反応する(追跡: #299)。外したウィジェットの `OnTap` が呼ばれることがある(追跡: #297)
  - `Hooks`(`FloatSoda.Hooks`)は一部だけの実装で、`UseState` などの補助メソッドは `NotImplementedException` を投げる(AGENTS.md の「Project Structure」「Widget/Element Tree」)。追跡: ※要確認(Issue が見つからない)
  - Flutter と挙動が違う箇所の一覧は、「Flutter の読み替え表」にある。差異を解消する作業の追跡は #224
  - アクセシビリティ(スクリーンリーダー向けの Semantics)は実装しない。VR のオーバーレイに出力先がないため(再編前の `docs/APIDesign.md` の「実装しない API」)。解除の条件は決まっていない
