# リファレンス

リファレンスは、引くための一覧を集めたタブです。読み物ではないので、調べたい場面に合うページを、サイドバーから開いてください。手順や使い方の説明は、[ガイド](../guide/Home.md)にあります。

## 型やプロパティを調べる

型やメンバーの正確な定義は、API リファレンスのタブに置きます。API リファレンスのタブが公開されるまでは、`src/` のソースにある XML ドキュメントコメントで引きます(追跡: #219)。

型の名前が分からないときは、先に[部品を目的から探す](find-widgets.md)を開いてください。目的から部品の名前が分かれば、その名前で定義を引けます。
