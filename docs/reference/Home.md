# リファレンス

リファレンスは、引くための一覧を集めたタブです。読み物ではないので、調べたい場面から該当するページを1つ開いてください。手順や使い方の説明は、[ガイド](../guide/Home.md)にあります。

## 使う前に確かめる

自分の環境で動くか、作りたいものが今できるかを、使い始める前に確かめる場面です。

| ページ | 答える問い |
| :-- | :-- |
| [動作環境](requirements.md) | 自分の PC、または配る相手の PC で動くか |
| [できないこと・まだ使えないもの](limitations.md) | 作りたいものが、今の FloatSoda でできるか |
| [作例のカタログ](sample-catalog.md) | 近い作例と、その動かし方は何か |

## 書いている途中で引く

コードを書いていて、部品の名前、Flutter との違い、言葉の意味のどれかが分からなくなった場面です。

| ページ | 答える問い |
| :-- | :-- |
| [部品を目的から探す](find-widgets.md) | 並べる、押す、動かすなど、目的に使う部品は何か |
| [Flutter の読み替え表](flutter-mapping.md) | Flutter の書き方は、そのまま通るか、変わるか、まだないか |
| [用語集](glossary.md) | docs やコードに出てくるこの言葉は、どういう意味か |
