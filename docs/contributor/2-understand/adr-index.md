## ト書き

### ADR とは何か、台帳とは何か

- 読み手が持って来るもの: 「この設計はなぜこうなのか」という疑問
- このページが渡すもの: 2つの1文の定義(ADR は決定を理由と別案つきで残す記録、台帳は Flutter との差異を項目ごとに残す記録)と、このページが引く場所であること。書き方は `../6-propose/write-adr.md` にある
- 読み手がすること: 調べたいのが決定か差異かを見分ける
- 次へ進む先: 「ステータスと種別の意味」

### ステータスと種別の意味

- 読み手が持って来るもの: 一覧の列の意味
- このページが渡すもの: ステータス5種類と、種別2種類の定義の表。台帳のラベル4種類の意味。`proposed` は承認されるまで決定として扱わないという注意
- 読み手がすること: 列の意味を確かめる
- 次へ進む先: 「決定の一覧」

### 決定の一覧

- 読み手が持って来るもの: 調べたい決定の見当
- このページが渡すもの: 番号、題名、種別、ステータス、決定日、関係するページの表。各行から ADR の本文へのリンク
- 読み手がすること: 行を探し、本文を開く
- 止まる箇所: 該当する決定がない場合は、まだ決定されていないか、記録されていない。`../6-propose/write-proposal.md` へ送る
- 次へ進む先: 「Flutter との差異の台帳」
- 【未決】一覧を手で書くか、ディレクトリから自動で生成するか。退避した ADR を戻す手順と番号の振り直しは、後回しにする

### Flutter との差異の台帳

- 読み手が持って来るもの: Flutter のコードを移植している、または移植されたコードをレビューしている
- このページが渡すもの: 台帳の入口(ラベル別の見方、`deliberate` が一次情報であること)と、台帳の項目の書式。層の解説の「Flutter と違うところ」からの戻りリンク
- 読み手がすること: 自分が移植するウィジェットに関わる差異がないか、台帳で探す
- 止まる箇所: 台帳に項目がなく、差異を作りたい場合は、`../4-write/port-from-flutter.md` と `../6-propose/write-adr.md` へ送る
- 次へ進む先: 「決定を足すとき」
- 【未決】台帳の項目を ADR に移す手順。移す前は、元のファイルへのリンクで案内する(docs 再編の決定、2026-10-16〜17)

### 決定を足すとき

- 読み手が持って来るもの: 新しい決定を記録したい
- このページが渡すもの: 書き方のページ(`../6-propose/write-adr.md`)へのリンク1つ
- 読み手がすること: リンク先へ進む
- 止まる箇所: なし。ここでこのページは終わる
