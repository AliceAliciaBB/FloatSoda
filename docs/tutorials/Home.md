# チュートリアル

## このタブでできること

このタブでは、手を動かして最初のオーバーレイを動かせます。SteamVR のダッシュボードに数字とボタンを出し、ボタンを押すと数字が増えるところまで作ります。「FloatSoda で何か動かしてみたい」と思ったら、まず最初のチュートリアルを通してください。

## 最初の1本

[最初のオーバーレイを作る](first-overlay.md)が、最初に通すチュートリアルです。完成すると、ダッシュボードに青い四角が出て、その中の数字をボタンで増やせます。<!-- ※要確認: 完成画面のスクリーンショットが未用意。first-overlay.md と同じ画像を撮影してから差し込む -->

始める前に、SteamVR と .NET の SDK が要ります。要るものの一覧は、リファレンスの[動作環境](../reference/requirements.md)にあります。準備の手順は、ガイドの[開発環境を用意する](../guide/3-prepare/set-up-environment.md)です。

## 終えたあと

このチュートリアルを終えたら、目的に合う行き先を1つ選んでください。

- 通しで1つのパネルを作りたい: ガイドの[表情切り替えパネルを作る](../guide/4-build/screen/expression-switcher.md)
- 作りたいものに近い作例から始めたい: リファレンスの[作例のカタログ](../reference/sample-catalog.md)
- C# が初めて、または Flutter や uGUI の経験があって読み替えが要る: ガイドの[準備する](../guide/Home.md#3-準備する)
